On considère la relation $F = a + \frac{b}{c d}$.

\smallskip

Lorsque $a = \frac{1}{2}$, $b = 3$, $c = 4$, $d = -\frac{1}{4}$, la valeur de $F$ est égale à :

\smallskip

\eamreponsesautom[2]{$-\frac{5}{2}$}{$-\frac{3}{2}$}{$\frac{5}{2}$}{$\frac{3}{2}$}
